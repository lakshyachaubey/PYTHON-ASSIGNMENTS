# Student Exam Score Analysis using Python

## Project Overview

This project analyzes student exam performance using Python libraries such as:

* NumPy
* Pandas
* Matplotlib

The program performs statistical analysis on student scores, identifies high and low performers, and visualizes the data using different charts.

---

# Features

* Generate and store student score data
* Calculate:

  * Total Marks
  * Average Marks
  * Mean
  * Median
  * Standard Deviation
* Identify:

  * Highest-performing student
  * Lowest-performing student
* Visualize data using:

  * Bar Graph
  * Line Plot
  * Histogram
  * Pie Chart
* Generate meaningful academic insights

# Statistical Analysis Performed

The program calculates:

## 1. Mean

Average marks for each subject.

## 2. Median

Middle value of marks for each subject.

## 3. Standard Deviation

Measures variation in student performance.

## 4. Total Marks

Sum of marks obtained by each student.

## 5. Average Marks

Average marks scored by each student.

---

# Visualizations

## 1. Bar Graph

Shows total marks scored by each student.

## 2. Line Plot

Displays average marks of students.

## 3. Histogram

Shows distribution of total marks.

## 4. Pie Chart

Represents subject-wise average performance.
